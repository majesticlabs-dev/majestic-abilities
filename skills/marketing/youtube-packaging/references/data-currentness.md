# YouTube Data Currentness Checks

Verify before analysis and record the date:

- which public metrics the interface and API currently expose, and which are estimates
- whether view, like, and comment counts are visible for every channel in the set
- current handling of Shorts, live, premiere, and members-only formats in public counts
- publication dates and whether a video was re-uploaded, unlisted, or edited after release
- current advertising, disclosure, and paid-promotion labeling rules for the format

Public data is incomplete. Impressions, click-through rate, average view duration, traffic source, and audience retention are creator-only and cannot be inferred from public counts. Do not treat subscriber counts as precise, compare raw views across channels of unlike size or age, or present a single high-performing video as a repeatable pattern without a baseline. Label every estimated baseline as an estimate and state the comparison window.
