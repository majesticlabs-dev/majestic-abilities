# Content Types

Choose the structure that matches search intent.

## Guide

Best for broad informational queries where the reader needs a map.

Shape:

1. direct answer
2. who it is for
3. core concepts
4. implementation or decision framework
5. examples
6. FAQ
7. CTA

Target: 3,000-8,000 words, depending on SERP depth.

## How-To

Best for task completion.

Shape:

1. result shown first
2. prerequisites
3. step-by-step workflow
4. troubleshooting
5. variants
6. common mistakes
7. CTA

Target: 1,500-3,500 words.

## Comparison

Best for commercial investigation.

Shape:

1. quick verdict
2. comparison table
3. best-fit scenarios
4. detailed comparison
5. switching costs
6. FAQ
7. recommendation

Target: 2,000-4,500 words.

## Listicle

Best for discovery and category exploration.

Shape:

1. selection criteria
2. ranked or grouped list
3. best-for labels
4. tradeoffs
5. buyer guidance
6. CTA

Avoid empty lists. Every item needs a reason to exist.

## Definition

Best for "what is" queries.

Shape:

1. 40-60 word definition
2. plain-English explanation
3. example
4. why it matters
5. related concepts
6. FAQ

## Data Study

Best when you have original or credible aggregated data.

Shape:

1. key finding
2. methodology
3. findings
4. implications
5. limitations
6. source table or notes

Never fake data. If the methodology is weak, say so.

## Template or Resource Library

Best when the reader wants an artifact.

Shape:

1. who this is for
2. template preview
3. how to use it
4. downloadable or copyable artifact
5. examples
6. mistakes to avoid

## Opinion / Point of View

Best when the SERP is generic and differentiation matters.

Shape:

1. thesis
2. why the common belief is wrong
3. evidence
4. tradeoff
5. what to do instead
6. CTA

## Case Study

Best for proof and BOFU support.

Shape:

1. outcome
2. starting context
3. constraint
4. work done
5. result
6. lesson
7. CTA
