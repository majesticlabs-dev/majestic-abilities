# Polish Pass

Run this after drafting and before SEO optimization.

## Pass 1: Argument

- Does the piece make one clear claim?
- Does every section support the search intent or buyer job?
- Is there a real point of view, or just aggregation?
- Are tradeoffs named clearly?

## Pass 2: Information Gain

Add at least one of:

- original framework
- specific example
- data point
- teardown
- decision tree
- operator lesson
- workflow artifact

If nothing new is added, the article is not ready.

## Pass 3: Humanization

Use the `humanizer` skill when available. At minimum, remove:

- generic intros
- filler transitions
- over-neat three-part lists
- fake neutrality
- unsupported claims
- bloated verbs

## Pass 4: Voice

Check the draft against `.seo/brand.md` when present.

Ask:

- Would this brand actually say this?
- Are claims within the claims guardrail?
- Is the CTA consistent with the offer?
- Does the tone match the buyer's risk level?

## Pass 5: Compression

Cut sentences that restate the header, explain the obvious, or repeat a point already made.
