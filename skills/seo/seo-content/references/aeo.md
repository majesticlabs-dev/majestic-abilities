# AEO and GEO Layer

SEO content should be structured for search engines and answer engines.

## Use Existing Skills When Available

- `aeo-scorecard` for measurement and readiness scoring.
- `geo-content-optimizer` for AI citation structure.
- `query-expansion-strategy` for query fan-out.
- `snippet-hunter` for featured snippet formatting.
- `schema-architect` for structured data notes.
- `llms-txt-builder` when site-level AI crawler guidance is in scope.

## In-Article AEO Checklist

- Direct answer in the first 2-3 sentences.
- Definition block for core concepts.
- FAQ section for high-intent questions.
- Named entities are consistent and unambiguous.
- Claims have nearby source context.
- Comparisons use tables with stable dimensions.
- Frameworks have memorable names and clear steps.

## Citation Blocks

Use short, source-backed blocks when the claim is likely to be cited.

Example:

```markdown
## Quick answer

[Concept] is [plain-English definition]. It matters because [specific buyer consequence].
```

## Avoid

- keyword stuffing
- fake statistics
- invented analyst-style claims
- thin FAQ sections that repeat the article
- answer-engine optimization that weakens human usefulness
