# Metrics and Forecasting

## Core formulas

- Coverage = eligible pipeline / remaining target
- Stage conversion = entries reaching next stage / eligible stage entries
- Win rate = won / (won + lost), using one defined cohort
- Velocity = opportunities × win rate × average value / average cycle
- Weighted pipeline = sum(value × calibrated probability)

Derive coverage from historical win rate, remaining time, stage mix, and creation capacity. A generic multiple is only a starting hypothesis. Back-test forecast categories against outcomes and recalibrate by segment when samples permit.

Keep sales metrics separate from cash survival analysis. CAC payback, LTV:CAC, and efficiency ratios depend on margin, retention, motion, and accounting choices; use them only as sourced, dated heuristics.
