# Visual Critique

Use this review after a substantial interface build or refinement has a rendered first pass. Judge the visible result, not the source code or the effort spent producing it.

## Evidence

Review representative desktop and mobile screenshots. Include important interaction states when they affect the design. For refinement work, keep comparable baseline screenshots when practical.

Record the product goal, audience, intended tone, and any supplied quality references. Treat references as a quality bar, not a layout to reproduce.

When an independent reviewer is available, provide only the screenshots and review context. Withhold code, implementation history, prior feedback, and target scores so those details do not bias the review.

## Review

Assess the interface in this order:

1. **Identity:** Is the chosen direction recognizable and appropriate to the product?
2. **Hierarchy:** Do scale, spacing, density, alignment, and negative space guide attention?
3. **Craft:** Are typography, color, media, texture, controls, and motion consistent?
4. **Clarity:** Are the purpose, primary action, and interactive states understandable?
5. **Restraint:** Which elements, effects, labels, containers, or animations weaken the design?
6. **Credibility:** Are claims, data, controls, and media plausible and functional?
7. **Resilience:** Does the design hold at small viewports, with keyboard input, visible focus, sufficient contrast, and reduced motion?

Compare the result with strong professional work in the selected direction. Do not reward novelty that reduces comprehension or usability.

## Output

Return:

- one sentence that states the overall judgment
- the strongest element to preserve
- no more than five gaps, ordered by user impact
- one concrete correction for each gap
- any critical functional, responsive, or accessibility problem

## Correction Loop

Fix the highest-impact gaps first, then render the affected viewports and states again. Use no more than two critique passes by default. Stop earlier when remaining changes are subjective, repetitive, or outside the requested scope.

Finish by removing anything that does not improve comprehension, hierarchy, trust, or delight. Report only checks supported by rendered or interaction evidence.
